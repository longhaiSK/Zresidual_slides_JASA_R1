\section{Introduction}\label{introduction}

This vignette demonstrates how Z-residual diagnostics can be used for a
continuous Bayesian regression model. We use an inverse Gaussian (IG)
example because, for continuous responses, the randomized survival
probability (RSP) reduces to the ordinary survival probability and no
auxiliary randomization is needed.

The demo uses one representative dataset with \(n=50\). It fits two
Bayesian IG models with the same response family but different mean
structures: a flexible piecewise model and a simpler linear model. We
then compute posterior and ISCV Z-residual diagnostics, together with
comparable PPC and HPC checks. The emphasis is on the applied workflow:
compute residuals, inspect residual plots, apply targeted tests against
covariates, and compare the conclusions with PPC/HPC summaries.

\section{Data-Generating Model}\label{data-generating-model}

For each observation, the covariates are generated as

\[
X_{i,1}\sim \mathrm{Unif}(0.5,15.5),\qquad
X_{i,2}\sim \mathrm{Binom}(1,0.5),\qquad
X_{i,3}\sim \mathrm{Binom}(1,0.5),
\]

and the five independent non-primary predictors are

\[
Z_{i,1},\ldots,Z_{i,5}\sim N(0,1).
\]

Let \(c=7.95\) and define

\[
B_i=(X_{i,1}-c)^2 I(X_{i,1}<c),\qquad
A_i=(X_{i,1}-c)^2 I(X_{i,1}\ge c).
\]

The response is generated from an inverse Gaussian distribution,

\[
Y_i\sim \mathrm{IG}(\mu_i,\lambda),\qquad \lambda=25,
\]

where

\[
\log(\mu_i)=
-0.80+0.012B_i+0.006A_i+0.40X_{i,2}-0.25X_{i,3}
+0.12Z_{i,1}-0.10Z_{i,2}+0.08Z_{i,3}-0.06Z_{i,4}+0.05Z_{i,5}.
\]

The two fitted Bayesian IG models use the same response family and log
link. They differ only in the mean structure:

\[
\begin{aligned}
\text{Piecewise IG:}\quad
\log(\mu_i)&=\alpha_0+\alpha_1B_i+\alpha_2A_i+\alpha_3X_{i,2}+\alpha_4X_{i,3}+\sum_{j=1}^5\gamma_j Z_{i,j},\\
\text{Linear IG:}\quad
\log(\mu_i)&=\alpha_0+\alpha_1X_{i,1}+\alpha_2X_{i,2}+\alpha_3X_{i,3}+\sum_{j=1}^5\gamma_j Z_{i,j}.
\end{aligned}
\]

\section{Practical Notes}\label{practical-notes}

\begin{itemize}
\tightlist
\item
  The rendered sections show the data-generating mechanism, fitted model
  formulas, representative posterior Z-residual plots, and
  single-dataset diagnostic p-values for a continuous IG example.
\item
  The response is continuous, so the RSP residuals do not require
  repeated auxiliary randomization.
\item
  Large multi-replication simulations can be run using the non-evaluated
  driver above, but they are not rendered by default because they
  require many repeated MCMC fits.
\end{itemize}
